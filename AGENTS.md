# AGENTS.md

`laccd-courses-pp-cli` is an agent-native, read-only **Go 1.26** CLI (plus a companion MCP server) over the LACCD eLumen **public course catalog**. It searches ~9,664 approved courses and every degree/certificate program across all 9 colleges, fetches full Outlines of Record as JSON, compares courses across colleges for articulation, and keeps an offline pure-Go SQLite mirror with full-text search. The tree is **generated by [CLI Printing Press](https://github.com/mvanhorn/cli-printing-press)** — treat it as generated output, not hand-authored source.

## Setup
- Install Go 1.26.4+ (matches `go.mod` `toolchain go1.26.4`).
- `go mod download` (Cobra, `pelletier/go-toml`, `modernc.org/sqlite` (pure Go, no CGO), `mark3labs/mcp-go`).
- No credentials or `.env`: the eLumen catalog is public and unauthenticated.

## Build & Run
```bash
make build-mcp   # -> bin/laccd-courses-pp-mcp   (builds cleanly)
make install-mcp # go install ./cmd/laccd-courses-pp-mcp
```
Heads-up: the Makefile's `build` and `install` targets point at `./cmd/laccd-courses-pp-cli`, which is **not present in this working tree** (only `cmd/laccd-courses-pp-mcp` is), so they fail locally. To get the CLI binary, install the published package:
```bash
go install github.com/johnnyrobot/laccd-courses-pp-cli/cmd/laccd-courses-pp-cli@latest
```
Then discover capabilities at runtime rather than trusting a stale list:
```bash
laccd-courses-pp-cli doctor --json
laccd-courses-pp-cli agent-context --pretty
laccd-courses-pp-cli which "<capability>" --json
laccd-courses-pp-cli <command> --help
```
Add `--agent` for JSON + compact + no-color + non-interactive; prefer `--dry-run` on unfamiliar commands.

## Testing
```bash
make test        # go test ./...   (passes)
make lint        # golangci-lint run  (config in .golangci.yml)
```
Tests live beside their code as `*_test.go` under `internal/cli`, `internal/client`, `internal/cliutil`, `internal/mcp` (+ `cobratree`), and `internal/store`, using in-repo fixtures (no network). Before a change is done, `go test ./...` and `golangci-lint run` must pass. `make build` will not pass here until the CLI main package is restored — validate with `make build-mcp` instead.

## Code Style
- Standard Go: `gofmt`/`goimports`, `internal/` package layout, one command per file under `internal/cli/`.
- Preserve the agent contract: non-interactive; every command supports `--json`, `--select`, `--dry-run`, `--agent`; errors to stderr; honor the exit-code map (`0/2/3/5/7/10`).
- Read-only — do not add remote-mutating commands.
- **Generated tree:** fix systemic problems upstream in Printing Press; keep local edits narrow; record intentional changes in a `.printing-press-patches/` sidecar so a reprint preserves them.

## Commit & PR Conventions
- Git repo: `github.com/johnnyrobot/laccd-courses-pp-cli`, default branch `main`.
- Do not commit `*.db*` mirrors, built binaries, `*.mcpb`, or `/.printing-press*.json` (see `.gitignore`).
- Never hand-bump `var version = ...` or `CHANGELOG.md`; the `mvanhorn/printing-press-library` publish workflow assigns the `YYYY.M.N` version. Keep PRs scoped and justify any generated-tree patch.

## Security & Data
- No secrets, tokens, or API keys — nothing to leak.
- Only public LACCD/eLumen catalog data flows through; the local SQLite mirror is public data and is gitignored.
- Network egress is limited to the public eLumen catalog. Respect its quirks: the list endpoint is 1-indexed (page 0 → 502) and cold-starts flakily; the client defaults `--page` to 1 and retries — don't paper over 502s by forcing page 0.
